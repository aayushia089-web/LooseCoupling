## 🌸 Overview

This project demonstrates the **Loose Coupling** design principle in Java using **interfaces and abstraction**.  
The implementation reduces dependencies between components, making the application easier to maintain, extend, and test.

---

## 🎯 Objectives

- Understand the concept of Loose Coupling
- Reduce direct dependencies between classes
- Improve code flexibility and scalability
- Follow Object-Oriented Design principles
- Create reusable and maintainable components

## 📖 What is Loose Coupling?

Loose Coupling is a software design principle where classes depend on abstractions rather than concrete implementations. This minimizes dependencies and allows components to evolve independently.
